# Joufflu controls

The controls Joufflu adds on top of the restyled natives, one optional package
each. They all build on the core `Joufflu` package and read the same design
tokens, so they follow the theme like the natives do.

| Section | Package | What's inside |
|---|---|---|
| [Feedback](../feedback/index.md) | `Joufflu.Feedback` | `Badge`, `Spinner`, toasts |
| [Inputs](../inputs/index.md) | `Joufflu.Inputs` | `NumericUpDown`, `DecimalUpDown`, `TimeSpanPicker`, `FormatTextBox`, `Search`, `ComboBoxSearch`, `ComboBoxTags`, `TextEditable`, `FilePicker`, `ColorPicker`, `Dropdown` |
| [Navigation](../navigation/index.md) | `Joufflu.Navigation` | `NavigationMenu`, overlays (modal dialogs), `Paging` |
| [Data](../data/index.md) | `Joufflu.Data` | `DataFill`, `DataEdit`, `DataDisplay` |
| [File explorer](../file-explorer/index.md) | `Joufflu.FileExplorer` | `ExplorerList`, `ExplorerTree`, `Explorer` and their sources |
